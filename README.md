# Tax Workbook Demo

## Tabs
1. Dashboard — `index.html`
2. Personal — `personal.html`
3–N. Each entity — `practice.html`, `management.html`, `real-estate.html`, `holdings.html`, or `entity.html?id=…` for new ones
4. Foreign Property — `foreign.html`
5. Tax Tools — `tax-tools.html`
6. **Setup** — `setup.html` ← rename / add / delete entities here

## Edit entity name
- Open **Setup** tab, edit the name field (auto-saves), or
- Open the entity tab and edit **Entity name** at the top

## Add new entity
1. Open **Setup**
2. Click **+ Add Entity**
3. Rename it in the table
4. Click **Open →** (or use the new sidebar tab)
